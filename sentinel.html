How this works. Every value on this page is measured, never typed: the scan re-runs the gates (Devouring Dragon kit sweep, Golden Lion sl2-goldenv, the Adaptive Prodigy ten-layer run_all), parses each serial's own status panel, counts chapter files on disk, and fetches the public profile README live. Re-run it any time with python3 tools/sentinel.py --kit /path/to/soul-land-universal-kit (in the soul-library repo). The profile check reads GitHub's raw CDN, which can lag a fresh push by a few minutes. First-run receipts: the Sentinel caught the profile one chapter behind (fixed same hour), a library miscount caused by a chapter variant (fixed: live-edge comparison), and two of its own bugs — a counter that counted non-chapters, and a pattern that missed titled filenames. A checker must measure the thing it claims to measure.
